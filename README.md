# ☁️ Cloud-Based Sales Dashboard

A simple cloud-based sales analytics project built using **Google Colab, Python, Pandas, and Matplotlib**.

## 📌 Project Overview

This project analyzes sales data and generates useful business insights through data processing and visualization.

## 🚀 Features

- Total sales calculation
- Total orders and quantity sold
- Product-wise sales analysis
- Category-wise sales analysis
- Region-wise sales analysis
- Monthly sales analysis
- Sales visualization
- Best-selling product identification
- Highest-performing region identification
- Business insights
- CSV dataset upload

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab

## ☁️ Cloud Component

Google Colab is used as the cloud computing environment. The sales dataset is processed and analyzed using Python in the cloud.

## ▶️ How to Run

1. Open the `.ipynb` file in Google Colab.
2. Run the cells from top to bottom.
3. Use the sample dataset or upload your own CSV sales dataset.
4. View the generated analysis, charts, and business insights.
